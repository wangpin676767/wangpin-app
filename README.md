## 安裝


1. 開啟 Releases，下載 Assets 下的 `.exe` 安裝檔。
2. 可下載對應 `.sha256` 檔案，用 PowerShell `Get-FileHash -Algorithm SHA256` 核對。
3. 執行安裝檔，依安裝畫面操作。
